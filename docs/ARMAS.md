# Armas

Você começa com as 8 armas equipadas. No **terminal de arsenal** (o computador com luz verde perto do
início da arena, tecla **E**) dá para escolher quais levar, e a ordem das equipadas define as teclas **1–8**.
Cada arma tem **3 melhorias** que podem ser ligadas e desligadas à vontade. Tudo fica salvo.

| # | Arma | Clique esquerdo | Clique direito |
|---|---|---|---|
| 1 | **Revólver** | Tiro preciso, 6 balas. Tiro na cabeça dá dano dobrado. | **Segure** para girar a arma e carregar o ricochete: quanto mais tempo, em mais inimigos a bala quica. |
| 2 | **Escopeta** | Leque de chumbo, a arma gira a cada tiro. 6 cartuchos. | **Rajada dupla**: gasta dois cartuchos e o coice te empurra (mire no chão para voar). |
| 3 | **Espadas aladas** | Arremessa uma das 4 espadas, que voltam sozinhas. Destroem projéteis no caminho. | **Tempestade**: as 4 espadas voam teleguiadas nos inimigos visíveis. Com espadas fora, chama todas de volta. |
| 4 | **Lança-foguetes** | Foguete explosivo; perto de você, te arremessa (salto-foguete). | **Segure** para guiar o míssil pela mira; soltar detona. |
| 5 | **Pregadora** | Rajada contínua. Esquenta e trava se superaquecer. | **Descarga térmica**: libera todo o calor num leque de pregos incandescentes. |
| 6 | **Fuzil de raio** | Raio que atravessa tudo na linha. Dano altíssimo, recarga lenta. | **Luneta** (zoom). |
| 7 | **Arpão** | Fisga e prende o inimigo com um cabo. | **Gancho**: te puxa até a parede ou o inimigo atingido. |
| 8 | **Lança-granadas** | Granadas que quicam e explodem no pavio ou ao tocar um inimigo. | **Detona** todas as granadas no ar. |

Além das armas:

- **R** gira a arma (inspeção) e recarrega revólver e escopeta.
- **F** é o soco: aparar um projétil laranja no momento certo congela o tempo por um instante e devolve o
  projétil muito mais forte, com uma explosão.

## Melhorias

| Arma | Melhoria | Efeito |
|---|---|---|
| Revólver | Tambor estendido | 8 balas em vez de 6 |
| | Ricochete rápido | Carrega o ricochete na metade do tempo |
| | Bala perfurante | O tiro normal atravessa inimigos |
| Escopeta | Cartuchos incendiários | Inimigos atingidos queimam por 3 s |
| | Carregador de tambor | 10 cartuchos |
| | Bombeamento rápido | Atira e recarrega bem mais rápido |
| Espadas aladas | Lâminas explosivas | Explodem no primeiro inimigo que atingem |
| | Asas velozes | Voam e voltam muito mais rápido |
| | Lâminas sagradas | Cada acerto cura 6 de vida |
| Lança-foguetes | Recarga automática | Recarrega na metade do tempo |
| | Fragmentação | A explosão espalha estilhaços incandescentes |
| | Salto potente | Salto-foguete 50% mais forte |
| Pregadora | Refrigeração | Esquenta 40% mais devagar |
| | Pregos saltitantes | Pregos quicam uma vez nas paredes |
| | Ímã | Pregos curvam até o inimigo mais próximo |
| Fuzil de raio | Capacitor | Recarga do raio em 0,9 s |
| | Sobrecarga | Cada acerto solta arcos elétricos em 2 inimigos próximos |
| | Raio largo | Atinge também quem estiver perto da linha do raio |
| Arpão | Cabo longo | Alcance de 40 para 70 |
| | Arpão farpado | Puxa o inimigo atingido até você |
| | Aterrissagem | Chegar pelo gancho causa uma explosão |
| Lança-granadas | Aderentes | Grudam em inimigos e superfícies |
| | Bomba cacho | Explode em 3 mini-granadas |
| | Pavio curto | Explode em 0,8 s e voa mais longe |
